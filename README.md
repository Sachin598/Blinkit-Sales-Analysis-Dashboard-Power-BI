# Blinkit Sales Analysis Dashboard | Power BI

## Project Overview
This project presents an interactive Power BI dashboard designed to analyze Blinkit's sales performance, product categories, outlet characteristics, and customer ratings.

The dashboard helps understand sales trends, compare outlet performance, and identify important business insights through interactive visualizations.

![Blinkit Sales Dashboard](Screenshots/dashboard.png)

## Tools & Technologies
- Power BI
- DAX (Data Analysis Expressions)
- Power Query
- Data Visualization
- Data Analysis

## Key Performance Indicators (KPIs)
- **Total Sales:** $1.2M
- **Average Sales:** $141.0
- **Number of Items:** 8,523
- **Average Rating:** 4.0

## Dashboard Features

### 1. Sales Performance Analysis
- Total Sales and Average Sales
- Sales by Item Type
- Outlet Establishment Year analysis

### 2. Product Analysis
- Fat Content distribution
- Sales by product category
- Item-level performance analysis

### 3. Outlet Analysis
- Outlet Size performance
- Outlet Location Tier analysis
- Outlet Type comparison
- Total Items and Average Rating by outlet

### 4. Interactive Filters
- Outlet Location Type
- Outlet Size
- Item Type

## Business Objectives
- Analyze overall sales performance.
- Identify high-performing product categories.
- Understand outlet-wise sales distribution.
- Compare sales across different outlet sizes and locations.
- Evaluate product ratings and item visibility.
